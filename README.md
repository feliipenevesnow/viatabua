# 🍷 Viatábua Bistrô - Landing Page (SPA)

Esta é uma Single Page Application (SPA) desenvolvida para o **Viatábua Bistrô**, um estabelecimento de alta gastronomia em Presidente Epitácio/SP, especializado em vinhos, frios, massas artesanais e drinks.

O objetivo foi criar uma experiência de usuário fluida, moderna e totalmente responsiva.

## 🛠️ Tecnologias e Abordagem

O projeto foi construído utilizando **Vanilla Web Development** (sem frameworks), focando na performance e no controle total do código:

* **HTML5**: Estruturação semântica.
* **CSS3**: Estilização customizada, layout responsivo e transições suaves.
* **JavaScript (Vanilla)**: Lógica da SPA, manipulação do DOM e carregamento dinâmico de dados.

## 📂 Estrutura de Arquivos

A organização do projeto é direta e limpa:

* `index.html`: Estrutura principal da aplicação.
* `style.css`: Responsável pela identidade visual e responsividade.
* `script.js`: Gerencia a navegação e interatividade.
* `data.js`: Centraliza os dados (como itens do cardápio), facilitando a manutenção sem mexer no HTML.
